# MVP 功能测试指南

**测试日期**: 2026-02-15
**功能**: 可编辑和可拖动的首页磁贴
**版本**: MVP (Phase 1-4 完成)

## ✅ 已实现的功能

### 1. 编辑模式入口和退出 (User Story 3)
- 点击"编辑"按钮进入编辑模式
- 点击"完成"按钮退出编辑模式
- 编辑模式视觉指示器（边框、按钮状态）
- 触觉反馈（移动端）
- 30秒无操作自动退出
- 导航离开时自动保存

### 2. 拖动磁贴重新排序 (User Story 1)
- 长按磁贴拖动重新排序（桌面/移动端）
- 拖动时的视觉反馈（缩放、阴影）
- 拖动时的触觉反馈（移动端）
- 点击排序回退（WeChat Mini Program）
- 性能监控
- 边缘情况处理（后台、旋转）

### 3. 显示/隐藏磁贴 (User Story 2 - 部分)
- 在编辑模式下隐藏磁贴
- 在已隐藏列表中重新显示磁贴
- 防止隐藏所有磁贴
- 空状态提示

### 4. 数据持久化
- 磁贴配置自动保存
- 应用重启后恢复配置
- 从旧格式自动迁移

## 📝 测试注意事项

1. **平台差异**:
   - Windows/macOS: 使用鼠标拖动
   - 移动端: 使用触摸拖动 + 触觉反馈
   - WeChat Mini Program: 使用点击排序

2. **数据持久化**:
   - 配置保存在 SharedPreferences
   - 键名: `tile_configurations`
   - 格式: JSON

3. **性能监控**:
   - 使用 PerformanceMonitor 跟踪拖动操作
   - 操作名: `tile_reorder`

4. **错误处理**:
   - 所有错误都有友好提示
   - 失败时自动回滚到之前状态
