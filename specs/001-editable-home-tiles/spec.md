# Feature Specification: 可编辑和可拖动的首页磁贴

**Feature Branch**: `001-editable-home-tiles`
**Created**: 2026-02-15
**Status**: Draft
**Input**: User description: "我想让首页的快捷方式（磁贴）变得可编辑且可拖动更改"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 拖动磁贴重新排序 (Priority: P1)

用户希望能够通过长按并拖动磁贴来重新排列首页快捷功能的顺序，以便将最常用的功能放在最显眼的位置。

**Why this priority**: 这是核心功能，直接满足用户个性化首页布局的需求。拖动排序是最直观的交互方式，用户无需进入设置页面即可快速调整。

**Independent Test**: 用户可以长按任意磁贴，拖动到新位置后释放，磁贴顺序立即改变并在下次打开应用时保持。

**Acceptance Scenarios**:

1. **Given** 首页显示3个磁贴（电费、校车、饭卡），**When** 用户长按"电费"磁贴并拖动到"饭卡"磁贴后面，**Then** 磁贴顺序变为：校车、饭卡、电费
2. **Given** 用户已重新排列磁贴顺序，**When** 用户关闭应用后重新打开，**Then** 磁贴顺序保持用户上次设置的顺序
3. **Given** 用户正在拖动磁贴，**When** 磁贴移动到其他磁贴上方时，**Then** 其他磁贴自动让出位置，提供视觉反馈（如阴影或高亮）
4. **Given** 用户开始拖动磁贴，**When** 拖动过程中，**Then** 被拖动的磁贴显示拖动状态（如轻微放大、阴影加深）

---

### User Story 2 - 显示/隐藏磁贴 (Priority: P2)

用户希望能够选择显示或隐藏某些磁贴，以便只在首页显示自己需要的功能，隐藏不常用的功能。

**Why this priority**: 这是个性化的重要补充，让用户可以精简首页内容。但相比拖动排序，这是次要需求，因为用户可以通过排序将不常用功能放在后面。

**Independent Test**: 用户可以进入编辑模式，选择隐藏某个磁贴，该磁贴从首页消失。用户可以通过设置或编辑模式重新显示已隐藏的磁贴。

**Acceptance Scenarios**:

1. **Given** 首页显示所有可用磁贴，**When** 用户进入编辑模式并点击"电费"磁贴的隐藏按钮，**Then** "电费"磁贴从首页消失
2. **Given** 用户已隐藏"电费"磁贴，**When** 用户进入编辑模式查看可用磁贴列表，**Then** "电费"磁贴显示为"已隐藏"状态，并提供"显示"按钮
3. **Given** 用户已隐藏某些磁贴，**When** 用户点击"显示"按钮，**Then** 该磁贴重新出现在首页末尾
4. **Given** 用户隐藏了所有磁贴，**When** 首页加载时，**Then** 显示提示信息"暂无快捷功能，请在编辑模式中添加"

---

### User Story 3 - 编辑模式入口和退出 (Priority: P1)

用户需要一个清晰的方式进入和退出磁贴编辑模式，以便在日常使用和编辑状态之间切换。

**Why this priority**: 这是P1和P2功能的前提条件。没有编辑模式入口，用户无法进行任何编辑操作。与拖动排序同等重要。

**Independent Test**: 用户可以通过点击编辑按钮进入编辑模式，在编辑模式下可以拖动磁贴或显示/隐藏磁贴，点击"完成"按钮退出编辑模式。

**Acceptance Scenarios**:

1. **Given** 用户在首页，**When** 用户点击"快捷功能"标题旁的编辑按钮（或长按空白区域），**Then** 进入编辑模式，所有磁贴显示编辑状态（如抖动动画、显示删除/隐藏按钮）
2. **Given** 用户在编辑模式，**When** 用户点击"完成"按钮，**Then** 退出编辑模式，磁贴恢复正常显示，所有更改已保存
3. **Given** 用户在编辑模式，**When** 用户点击返回按钮或导航到其他页面，**Then** 自动退出编辑模式并保存更改
4. **Given** 用户在编辑模式，**When** 编辑模式持续超过30秒无操作，**Then** 自动退出编辑模式并保存更改

---

### Edge Cases

- 当用户拖动磁贴到屏幕边缘时，如何处理？（假设：磁贴不能拖出可见区域，拖到边缘时停止）
- 当只有1个磁贴时，拖动功能如何表现？（假设：仍可拖动，但位置不变，提供触觉反馈）
- 当用户在拖动过程中旋转屏幕或应用进入后台时，如何处理？（假设：取消拖动操作，磁贴恢复原位）
- 当磁贴数据加载失败时，编辑模式如何表现？（假设：显示错误提示，禁用编辑功能）
- 当用户快速连续拖动多个磁贴时，如何防止状态冲突？（假设：同一时间只允许拖动一个磁贴）
- 在不同平台（iOS、Android、Web、桌面）上，拖动交互如何适配？（假设：移动端使用触摸拖动，桌面端支持鼠标拖动，Web端支持两者）

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统必须允许用户通过长按磁贴（移动端）或鼠标拖动（桌面端）来重新排列磁贴顺序
- **FR-002**: 系统必须在用户拖动磁贴时提供实时视觉反馈，包括被拖动磁贴的状态变化和其他磁贴的位置调整
- **FR-003**: 系统必须在用户完成拖动后立即保存新的磁贴顺序，并在下次启动应用时恢复该顺序
- **FR-004**: 系统必须提供编辑模式入口，位于"快捷功能"标题旁边，以图标或文字按钮形式呈现
- **FR-005**: 系统必须在编辑模式下显示所有可用磁贴的列表，包括当前显示和已隐藏的磁贴
- **FR-006**: 用户必须能够在编辑模式下隐藏任意磁贴，隐藏后该磁贴不在首页显示
- **FR-007**: 用户必须能够在编辑模式下重新显示已隐藏的磁贴，显示后该磁贴出现在首页末尾
- **FR-008**: 系统必须在编辑模式下为每个磁贴提供隐藏/显示切换按钮
- **FR-009**: 系统必须提供明确的退出编辑模式方式，包括"完成"按钮、返回按钮、或导航到其他页面
- **FR-010**: 系统必须在退出编辑模式时自动保存所有更改（磁贴顺序和显示/隐藏状态）
- **FR-011**: 系统必须将磁贴配置（顺序和显示状态）持久化存储到本地，使用现有的 `TileService.setTiles()` 方法或扩展该方法
- **FR-012**: 系统必须在所有支持的平台（iOS、Android、macOS、Windows、Linux、Web、WeChat Mini Program）上提供一致的编辑体验
- **FR-013**: 系统必须在拖动过程中提供触觉反馈（移动端）或视觉反馈（桌面端）
- **FR-014**: 系统必须在用户隐藏所有磁贴时显示友好提示信息，引导用户重新添加磁贴
- **FR-015**: 系统必须在编辑模式下禁用磁贴的正常点击功能（如跳转到详情页），防止误操作

### Key Entities

- **磁贴配置 (TileConfiguration)**: 表示单个磁贴的配置信息，包含磁贴标识（如"电费"、"校车"、"饭卡"）、显示顺序（整数索引）、显示状态（显示/隐藏）
- **磁贴列表 (TileList)**: 表示用户的完整磁贴配置，包含所有可用磁贴的配置信息，按显示顺序排列，持久化存储到本地

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 用户可以在3秒内完成一次磁贴拖动排序操作（从长按到释放）
- **SC-002**: 用户可以在5秒内进入编辑模式、隐藏一个磁贴、并退出编辑模式
- **SC-003**: 磁贴顺序和显示状态的更改在应用重启后100%保持一致
- **SC-004**: 拖动操作在所有支持的平台上响应时间低于100毫秒（从触摸/点击到视觉反馈）
- **SC-005**: 90%的用户在首次使用时能够发现并成功使用编辑功能（通过用户测试验证）
- **SC-006**: 编辑模式下的所有操作（拖动、隐藏、显示）不会导致应用崩溃或数据丢失
- **SC-007**: 磁贴配置数据的存储和读取操作在100毫秒内完成

## Assumptions

- 假设当前应用已有的磁贴类型（电费、校车、饭卡）是固定的，本功能不涉及添加新类型的磁贴
- 假设磁贴的内容和功能保持不变，仅改变显示顺序和可见性
- 假设用户设备有足够的存储空间来保存磁贴配置（配置数据量很小，通常小于1KB）
- 假设用户在编辑模式下的操作是有意的，不需要"撤销"功能（可在后续版本中添加）
- 假设磁贴的拖动范围限制在磁贴网格区域内，不支持拖动到其他页面组件
- 假设编辑模式的入口按钮位于"快捷功能"标题旁边，不占用额外的屏幕空间
- 假设所有平台使用相同的磁贴配置存储机制（基于 `shared_preferences` 或类似的本地存储）

## Out of Scope

- 添加新类型的磁贴或自定义磁贴内容
- 磁贴的尺寸调整（如1x1、1x2、2x2等不同大小）
- 磁贴的分组或分类功能
- 磁贴配置的云端同步或跨设备同步
- 撤销/重做编辑操作
- 磁贴的复制或删除（仅支持隐藏）
- 磁贴的高级自定义（如更改图标、颜色、标题）
