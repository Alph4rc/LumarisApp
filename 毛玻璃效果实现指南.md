# Flutter 毛玻璃效果（Blur / Frosted Glass）实现指南

本指南详细讲解如何在 Flutter 应用中为 AppBar 和底部导航栏实现 iOS 风格的毛玻璃模糊效果，支持亮色/暗色主题自动切换。

---

## 核心原理

毛玻璃效果由三个元素叠加而成：

```
┌──────────────────────────────────┐
│  半透明颜色叠加层 (DecoratedBox)   │  ← 提供磨砂质感
├──────────────────────────────────┤
│  高斯模糊层 (BackdropFilter)       │  ← 模糊后面的内容
├──────────────────────────────────┤
│  被模糊的内容 (页面 body)           │  ← 滚动到此区域下方的实际内容
└──────────────────────────────────┘
```

Flutter 的 `BackdropFilter` 会对 **该 Widget 后方屏幕上已绘制的所有像素** 应用一个图像滤镜（此处为 `ImageFilter.blur`），从而实现透过毛玻璃看到模糊背景的效果。

**关键点：** `BackdropFilter` 模糊的是它**背后**的内容，不是它自身。因此必须用 `extendBodyBehindAppBar: true` 或 `extendBody: true` 让页面内容延伸到模糊区域下方，否则背后是空的，没有内容可模糊。

---

## 第一步：创建通用的 BlurWidget 组件

新建 `lib/blur_widget.dart`，这是整个效果的核心组件：

```dart
import 'dart:ui';
import 'package:flutter/material.dart';

/// 模糊组件 —— 为子组件添加毛玻璃背景效果
class BlurWidget extends StatelessWidget {
  const BlurWidget({
    super.key,
    this.child,
    this.sigmaX = 20,       // 水平模糊强度，默认 20
    this.sigmaY = 20,       // 垂直模糊强度，默认 20
    this.radius = BorderRadius.zero,  // 圆角，默认无圆角
  });

  final double sigmaX;
  final double sigmaY;
  final Widget? child;
  final BorderRadius radius;

  @override
  Widget build(BuildContext context) {
    ThemeData theme = Theme.of(context);
    return ClipRRect(
      borderRadius: radius,
      child: BackdropFilter.grouped(
        filter: ImageFilter.blur(sigmaX: sigmaX, sigmaY: sigmaY),
        child: DecoratedBox(
          decoration: BoxDecoration(color: theme.shadowColor),
          child: child,
        ),
      ),
    );
  }
}
```

### 逐层解析

| 层级 | Widget | 作用 |
|------|--------|------|
| 外层 | `ClipRRect` | 将模糊效果裁剪为圆角矩形（`radius` 可配） |
| 中层 | `BackdropFilter.grouped` | 对背后所有像素做高斯模糊。`grouped` 构造方法会将多个 BackdropFilter 合并为一个，提升性能 |
| 内层 | `DecoratedBox` | 在半透明模糊层之上再叠加一层颜色，形成"磨砂玻璃"的质感 |

> **sigma 取值建议：** 10~20 适合轻度毛玻璃，20~30 适合强模糊效果。值越大性能消耗越高。

## 第二步：配置主题颜色

在 `lib/main.dart` 的 `MaterialApp` 中配置主题。核心技巧是**复用 `ThemeData.shadowColor` 属性**来存储毛玻璃的叠加颜色：

```dart
import 'package:flutter/material.dart';
import 'package:flutter/services.dart';

/* 亮色主题的毛玻璃叠加色：白色半透明 */
const Color glassColor = Color.fromARGB(100, 255, 255, 255);

/* 暗色主题的毛玻璃叠加色：黑色半透明 */
const Color glassDarkColor = Color.fromARGB(120, 0, 0, 0);

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'Flutter Demo',
      themeMode: ThemeMode.light,        // 或 ThemeMode.system 跟随系统
      theme: ThemeData(
        colorScheme: ColorScheme.light(),
        // ⬇ 关键：AppBar 背景设为透明，否则 BackdropFilter 后面是纯色
        appBarTheme: AppBarTheme(
          backgroundColor: Colors.transparent,
          foregroundColor: Colors.black,
          shadowColor: Colors.transparent,
          systemOverlayStyle: SystemUiOverlayStyle.dark,
        ),
        // ⬇ 关键：shadowColor 在这里被复用为毛玻璃的叠加颜色
        shadowColor: glassColor,
        // 底部导航栏文字/图标颜色（可选）
        bottomNavigationBarTheme: BottomNavigationBarThemeData(
          selectedItemColor: Colors.black,
          unselectedItemColor: Colors.black45,
        ),
      ),
      darkTheme: ThemeData(
        colorScheme: ColorScheme.dark(),
        appBarTheme: AppBarTheme(
          backgroundColor: Colors.transparent,
          foregroundColor: Colors.white70,
          shadowColor: Colors.transparent,
          systemOverlayStyle: SystemUiOverlayStyle.light,
        ),
        shadowColor: glassDarkColor,
        scaffoldBackgroundColor: Colors.black,
        bottomNavigationBarTheme: BottomNavigationBarThemeData(
          selectedItemColor: Colors.white,
          unselectedItemColor: Colors.white54,
        ),
      ),
      home: const HomePage(),
    );
  }
}
```

### 配置要点

1. **`appBarTheme.backgroundColor = Colors.transparent`** — 必须将 AppBar 背景设为透明，否则 AppBar 自身的颜色会挡住要模糊的内容。
2. **`shadowColor`** — 这里没有用它来做阴影，而是"借用"这个属性存储毛玻璃的叠加颜色。`BlurWidget` 内部通过 `theme.shadowColor` 读取，这样亮色/暗色主题会自动切换。你也可以用 `colorScheme` 的某个槽位，效果相同。
3. **`appBarTheme.shadowColor = Colors.transparent`** — 去掉 AppBar 自带的阴影，避免干扰毛玻璃效果。

## 第三步：为 AppBar 添加毛玻璃效果

在任意页面的 `Scaffold` 中：

```dart
import 'package:your_app/blur_widget.dart';
import 'package:flutter/material.dart';

class HomePage extends StatelessWidget {
  const HomePage({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text("Title"),
        actions: [
          IconButton(icon: Icon(Icons.settings), onPressed: () {}),
        ],
        // ⬇ 将 BlurWidget 放入 flexibleSpace，撑满整个 AppBar
        flexibleSpace: BlurWidget(child: SizedBox.expand()),
      ),
      // ⬇ 必须开启！让 body 内容延伸到 AppBar 下方
      extendBodyBehindAppBar: true,
      body: ListView(
        children: [
          // 列表内容会滚动到 AppBar 下方，被 BackdropFilter 模糊
          Image.asset("images/photo1.jpg"),
          Image.asset("images/photo2.jpg"),
          // ...
        ],
      ),
    );
  }
}
```

### 工作原理

```
         ┌──────────────────────┐
         │  系统状态栏           │
         ├──────────────────────┤
         │  Title    🔔 ⚙️      │  ← AppBar (背景透明)
         │  ╔══════════════╗    │
         │  ║ BlurWidget   ║    │  ← flexibleSpace 中的 BlurWidget
         │  ║  (模糊+叠加)  ║    │     对下方图片做模糊处理
         │  ╚══════════════╝    │
         ├──────────────────────┤
         │                      │
         │  🖼️ 图片内容        │  ← body（延伸到 AppBar 下方）
         │                      │
         │                      │
         └──────────────────────┘
```

- `extendBodyBehindAppBar: true` 告诉 Scaffold 的 body 从屏幕顶部（系统状态栏下方）开始布局，而不是从 AppBar 下方开始。
- `flexibleSpace` 中的 `BlurWidget` + `SizedBox.expand()` 铺满整个 AppBar 区域。
- 当列表滚动时，图片经过 AppBar 区域，其像素被 `BackdropFilter` 捕获并模糊。

> **注意：** 如果 body 顶部有内容被 AppBar 遮挡，需要在 body 顶部添加 `SizedBox(height: kToolbarHeight + MediaQuery.of(context).padding.top)` 作为占位，或使用 `SafeArea`（但 SafeArea 需要 `bottom: false`，否则底部导航栏也会被影响）。

## 第四步：为底部导航栏添加毛玻璃效果

底部导航栏的实现方式与 AppBar 类似，但有两处不同：

1. 使用 `extendBody: true`（而不是 `extendBodyBehindAppBar`）
2. 自定义导航菜单（不使用系统 `BottomNavigationBar`），以便完全控制样式

```dart
import 'package:your_app/blur_widget.dart';
import 'package:flutter/material.dart';

class FramePage extends StatefulWidget {
  const FramePage({super.key});

  @override
  State<FramePage> createState() => _FramePageState();
}

class _FramePageState extends State<FramePage> {
  int pageIndex = 0;

  final List<Widget> pages = [HomePage(), MinePage()];

  @override
  Widget build(BuildContext context) {
    ThemeData themeData = Theme.of(context);
    return Scaffold(
      body: pages[pageIndex],
      // ⬇ 必须开启！让 body 内容延伸到导航栏下方
      extendBody: true,
      // ⬇ 直接将 BlurWidget 作为 bottomNavigationBar
      bottomNavigationBar: BlurWidget(
        child: _buildMenus(themeData),
      ),
    );
  }

  /// 自定义底部菜单
  Widget _buildMenus(ThemeData themeData) {
    return SafeArea(
      child: Padding(
        padding: EdgeInsets.symmetric(vertical: 15),
        child: Row(
          children: [
            Expanded(
              child: _buildItem(
                themeData,
                Icons.home,
                "HOME",
                pageIndex == 0,
                onTap: () => setState(() => pageIndex = 0),
              ),
            ),
            Expanded(
              child: _buildItem(
                themeData,
                Icons.person,
                "MINE",
                pageIndex == 1,
                onTap: () => setState(() => pageIndex = 1),
              ),
            ),
          ],
        ),
      ),
    );
  }

  Widget _buildItem(
    ThemeData themeData,
    IconData icon,
    String text,
    bool isSelected, {
    Function()? onTap,
  }) {
    return GestureDetector(
      behavior: HitTestBehavior.opaque,
      onTap: onTap,
      child: Column(
        spacing: 5,
        mainAxisSize: MainAxisSize.min,
        children: [
          Icon(
            icon,
            color: isSelected
                ? themeData.bottomNavigationBarTheme.selectedItemColor!
                : themeData.bottomNavigationBarTheme.unselectedItemColor!,
          ),
          Text(
            text,
            style: TextStyle(
              color: isSelected
                  ? themeData.bottomNavigationBarTheme.selectedItemColor!
                  : themeData.bottomNavigationBarTheme.unselectedItemColor!,
            ),
          ),
        ],
      ),
    );
  }
}
```

### 工作原理

```
         ┌──────────────────────┐
         │                      │
         │  page content        │  ← body（延伸到导航栏下方）
         │                      │
         │                      │
         ├──────────────────────┤
         │  ╔══════════════╗    │
         │  ║ BlurWidget   ║    │  ← bottomNavigationBar
         │  ║  (模糊+叠加)  ║    │     对上方内容做模糊
         │  ╚══════════════╝    │
         │   HOME  │  MINE      │  ← 自定义导航菜单
         ├──────────────────────┤
         │  系统手势指示条       │
         └──────────────────────┘
```

- `extendBody: true` 告诉 Scaffold 的 body 布局时延伸到导航栏下方，这样 `BackdropFilter` 才能捕获到后面有内容。
- 自定义导航菜单放在 `SafeArea` 中，确保在有 Home Indicator 的设备上不会被遮挡。
- 选中/未选中的颜色从 `themeData.bottomNavigationBarTheme` 读取，与主题保持一致。

## 关键属性对照表

| Scaffold 属性 | 作用 | 毛玻璃场景 |
|---|---|---|
| `extendBodyBehindAppBar: true` | body 延伸到 AppBar 下方 | AppBar 毛玻璃 |
| `extendBody: true` | body 延伸到底部导航栏下方 | 底部导航栏毛玻璃 |
| `AppBar.flexibleSpace` | AppBar 的灵活空间，可放入任意 Widget | 放入 BlurWidget 实现模糊 |
| `AppBar.backgroundColor: transparent` | AppBar 背景透明 | 在 Theme 中全局设置 |

---

## 性能注意事项

1. **`BackdropFilter.grouped`** — 优先使用 `.grouped` 构造方法而非 `.new`，它会将页面中多个 BackdropFilter 合并为一个，减少 GPU 绘制开销。
2. **sigma 值** — 不要设置过大（建议 ≤ 30），值越大 GPU 计算量越大。
3. **裁剪** — 如果不需要圆角，将 `radius` 设为 `BorderRadius.zero`，避免额外的裁剪开销。
4. **避免嵌套** — 不要在已被 `BackdropFilter` 覆盖的区域内再嵌套另一个 `BackdropFilter`，会导致多次离屏渲染。
